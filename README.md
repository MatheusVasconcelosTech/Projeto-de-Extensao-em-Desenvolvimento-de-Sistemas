# BemEstar+ — Projeto de Extensão em Desenvolvimento de Sistemas

## 1. Apresentação do projeto

A **BemEstar+** é uma empresa fictícia criada para este projeto acadêmico, com foco na integração entre saúde, tecnologia e bem-estar.

O projeto propõe uma solução computacional para auxiliar na organização e no acompanhamento da rotina de utilização de medicamentos, especialmente para pessoas idosas e pessoas que fazem uso contínuo ou frequente de medicamentos. A solução também poderá apoiar familiares e cuidadores.

A aplicação busca centralizar informações sobre usuários, medicamentos, horários e registros de utilização, além de disponibilizar recursos de lembretes e acompanhamento. Seu objetivo é facilitar a organização da rotina e contribuir para a autonomia e a qualidade de vida dos usuários.

**Importante:** o sistema tem caráter exclusivamente organizacional e informativo. Não realiza diagnósticos, prescrições ou alterações de tratamentos, nem substitui a orientação de profissionais de saúde.

### Objetivos

- Desenvolver uma solução digital para apoiar a organização da rotina de medicamentos.
- Modelar o sistema utilizando Engenharia de Software e diagramas UML.
- Desenvolver funcionalidades em C#.
- Projetar e implementar um banco de dados com SQL.
- Aplicar os conhecimentos adquiridos nas disciplinas envolvidas no projeto.
